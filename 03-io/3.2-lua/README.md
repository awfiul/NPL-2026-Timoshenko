# 3.2. Проверка ответов тренировочного теста

**Язык:** Lua

## Условие

Прочитать ключ из текстового файла (один ответ на строку), запросить столько же ответов в консоли. Записать в отчёт число совпадений и номера ошибочных ответов с единицы. Удалять крайние пробелы.

## Пример

Ключ A, C, B и ответы A, B, B дают 2/3 и один ошибочный номер 2.
