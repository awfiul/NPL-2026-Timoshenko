# 3.3. Сверка списка иллюстраций

**Язык:** Perl

## Условие

Прочитать файл с ожидаемыми именами иллюстраций по одному на строку. Сравнить множество имён с обычными файлами указанной папки без обхода подпапок. Напечатать отсортированные списки отсутствующих и лишних файлов.

## Пример

Ожидаются a.png и b.png, в папке лежат b.png и c.png. Отсутствует a.png, лишний файл — c.png.
