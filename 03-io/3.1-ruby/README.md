# 3.1. Журнал гитарных занятий

**Язык:** Ruby

## Условие

Реализовать консольные команды add и total. Первая дописывает в TSV дату, упражнение и целое положительное число минут. Вторая суммирует время по выбранному упражнению за все даты. Неверную запись отклонить до изменения файла.

## Пример

После записей «слайды» на 12 и 8 минут и «аккорды» на 5 минут запрос total для слайдов выводит 20.
