# 3.4. Дневник наблюдений за погодой

**Язык:** Nim

## Условие

Прочитать из файла строки с датой и температурой через табуляцию. Запросить в консоли порог, записать в новый файл даты с температурой строго ниже порога в исходном порядке. Для испорченной строки вывести её номер.

## Пример

При пороге 0 и значениях −3, 0, 2 в выходной файл попадёт только дата первого наблюдения.
