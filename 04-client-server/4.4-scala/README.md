# 4.4. Сервер табло викторины

**Язык:** Scala

## Условие

Написать TCP-сервер и клиент для localhost. Команда SCORE имя баллы добавляет целое число баллов игроку, TOP возвращает лидера и сумму. При равенстве выбрать первое имя по алфавиту. Состояние хранится в памяти между подключениями.

## Пример

После SCORE Eva 4, SCORE Anna 2 и SCORE Anna 2 ответ на TOP — Anna 4. До первой записи ответ — EMPTY.
