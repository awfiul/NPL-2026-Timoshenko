# 4.3. Сервис расчёта печати фотографий

**Язык:** Groovy

## Условие

Написать локальный TCP-сервер и клиент. Клиент передаёт строку из формата и количества. Сервер считает стоимость по фиксированному тарифу: S — 15 рублей, L — 25 рублей за отпечаток. Для неизвестного формата или неположительного количества вернуть ERROR.

## Пример

Запрос L 3 даёт ответ 75. Запрос S 0 даёт ERROR.
