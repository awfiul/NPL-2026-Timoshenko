# 4.2. Бронирование мест на показ

**Язык:** Erlang

## Условие

Реализовать TCP-клиент и сервер на localhost на пять пронумерованных мест. Сервер хранит состояние сеанса показа между запросами. BOOK n резервирует свободное место, FREE n освобождает занятое. Обрабатывать команды последовательно.

## Пример

Два клиента по очереди отправляют BOOK 2. Первый получает OK, второй BUSY. После FREE 2 место снова доступно.
