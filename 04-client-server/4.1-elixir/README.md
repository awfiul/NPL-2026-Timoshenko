# 4.1. Электронная очередь в фотостудию

**Язык:** Elixir

## Условие

Реализовать TCP-сервер на localhost и консольный клиент. Сервер хранит очередь между подключениями. Команда JOIN с именем добавляет запись, NEXT удаляет и возвращает первое имя, SIZE сообщает длину. Одна строка — одна команда или ответ.

## Пример

После JOIN Anna и JOIN Eva запрос NEXT возвращает Anna, затем SIZE возвращает 1. Для пустой очереди NEXT возвращает EMPTY.
