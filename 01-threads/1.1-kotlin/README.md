# 1.1. Пики громкости в аудиозаписи

**Язык:** Kotlin

## Условие

Разбить массив целых отсчётов на последовательные окна длины W, включая последнее неполное окно. Распределить окна между потоками и вернуть максимальный модуль отсчёта каждого окна в исходном порядке.

## Пример

При W = 2 для [−4, 3, 1, −7, 2] результат равен [4, 7, 2].
