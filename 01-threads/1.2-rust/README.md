# 1.2. Гистограмма яркости изображения

**Язык:** Rust

## Условие

Разделить строки прямоугольной матрицы яркостей 0–255 между потоками. Каждый поток строит свою гистограмму из четырёх равных диапазонов. Сложить счётчики и сверить результат с последовательным обходом.

## Пример

Для строк [0, 64, 255] и [63, 127, 128] частоты диапазонов равны [2, 2, 1, 1].
