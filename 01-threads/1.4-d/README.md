# 1.4. Расход бумаги по тиражам

**Язык:** D

## Условие

Для списка заказов (страниц в экземпляре, число экземпляров) параллельно подсчитать расход листов при двусторонней печати. Каждый экземпляр начинается с нового листа. Объединить частичные суммы и сверить с расчётом в одном потоке.

## Пример

Для заказов (3,10) и (4,5) потребуется 20 + 10 = 30 листов.
