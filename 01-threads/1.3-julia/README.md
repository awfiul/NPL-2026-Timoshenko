# 1.3. Расстояние до ближайшей станции

**Язык:** Julia

## Условие

Для каждой точки на плоскости определить ближайшую из заданных станций по квадрату евклидова расстояния. Распределить точки между потоками. При равенстве выбрать первую станцию по порядку входа.

## Пример

Станции A(0,0), B(4,0). Для точек (1,0), (2,0), (4,1) вывести A, A, B.
