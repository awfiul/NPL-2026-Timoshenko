# 5.2. Журнал результатов EDN → TSV

**Язык:** Clojure

## Условие

Прочитать EDN-вектор записей с ключами :id, :correct и :total. Записать таблицу TSV с колонками id, correct, total, percent. Округлить процент до ближайшего целого, половины вверх. Проверить, что total > 0 и 0 ≤ correct ≤ total. Идентификаторы состоят из букв и цифр.

## Пример

Для [{:id "A7" :correct 3 :total 4}] строка таблицы содержит A7, 3, 4, 75 через табуляцию.
