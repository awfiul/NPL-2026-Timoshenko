# 5.1. Палитра HEX → таблица RGB

**Язык:** Swift

## Условие

Прочитать файл с одним цветом #RRGGBB на строку, перевести пары шестнадцатеричных цифр в десятичные числа и сформировать CSV с заголовком r,g,b. При неверном цвете указать номер строки.

## Пример

Строка #FFA010 преобразуется в строку 255,160,16.
