# 5.4. Список реплик TSV → субтитры SRT

**Язык:** Ada

## Условие

Прочитать начальное и конечное время в миллисекундах и однострочный текст через табуляцию. Преобразовать каждую запись в пронумерованный блок SRT с таймкодами HH:MM:SS,mmm и пустой строкой между блоками. Проверить, что конец позже начала.

## Пример

Для начала 1250 и конца 3400 строка времени первого блока имеет вид 00:00:01,250 --> 00:00:03,400.
