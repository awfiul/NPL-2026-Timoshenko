# 5.3. Сетка пикселей → изображение PBM

**Язык:** Lisp

## Условие

На Common Lisp преобразовать прямоугольную текстовую сетку из точек и решёток в текстовый PBM (P1). Решётку считать чёрным пикселем, точку — белым. Проверить ширину строк и допустимые символы.

## Пример

Для двух строк «.#» и «##» получится заголовок P1, размеры 2 2 и строки пикселей 0 1 и 1 1.
