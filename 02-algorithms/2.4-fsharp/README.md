# 2.4. Максимальная загрузка аудитории

**Язык:** F#

## Условие

По интервалам присутствия студентов найти максимальное число одновременно присутствующих и первый момент достижения максимума. Начало интервала включительно, конец исключительно. Обработать события одной минуты вместе.

## Пример

Для интервалов [10,20), [15,25), [20,30) максимум равен 2 и впервые достигается в минуту 15.
