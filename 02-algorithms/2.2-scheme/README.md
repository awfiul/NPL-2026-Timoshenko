# 2.2. Разбиение строки на слова из словаря

**Язык:** Scheme

## Условие

Рекурсивно подсчитать число способов полностью разбить строку на непустые слова из заданного множества. Для каждого подходящего префикса решить задачу для остатка строки. Сохранять результаты по позиции.

## Пример

Для строки «какао» и слов {«ка», «као», «о»} есть два разбиения: «ка + као» и «ка + ка + о».
