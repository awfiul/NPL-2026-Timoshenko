# 2.1. Длительность плейлиста с повторами

**Язык:** Haskell

## Условие

Задать плейлист деревом из трёх типов узлов: трек с длительностью в секундах, последовательность и повтор блока заданное число раз. Рекурсивно вычислить общую длительность без разворачивания повторов.

## Пример

Последовательность из трека на 30 с и трёх повторов блока [10 с, 5 с] длится 75 с. Пустая последовательность длится 0 с.
