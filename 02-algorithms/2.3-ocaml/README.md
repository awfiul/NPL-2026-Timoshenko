# 2.3. Самая длинная серия занятий

**Язык:** OCaml

## Условие

По неотсортированному списку номеров дней занятий определить самую длинную серию последовательных дней. Убрать дубли, при равенстве выбрать более раннюю серию. Для пустого списка вывести длину 0.

## Пример

Дни [8, 3, 2, 8, 9, 4] дают серию 2–4 длиной 3.
